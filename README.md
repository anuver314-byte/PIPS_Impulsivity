# PIPS Impulsivity Project

## Overview

This repository contains the code and supporting materials for our group project in Programming in Psychological Science (PIPS) at the University of Amsterdam (UvA).

The repository is being developed collaboratively and includes the components needed to implement the project, run simulations, and analyse the resulting data.

## Project Components

### Go/No-Go Experiment

The project includes a Go/No-Go task developed using Python and PsychoPy. This type of task involves responding to designated Go stimuli while withholding responses to No-Go stimuli. The final task design and implementation will be documented as the experiment is developed and tested.

### R Simulation and Analysis

The repository also includes an R Markdown document (`main.Rmd`) and supporting folders for data and tests. The purpose, methods, and outputs of the R component will be documented once the implementation has been finalised.

## Repository Structure

- `R/` — R scripts and related materials.
- `data/` — Data used or generated by the project, subject to the project's data-management requirements.
- `tests/` — Tests and checks for the project code.
- `main.Rmd` — The main R Markdown document, currently under development.
- `README.md` — Project overview and instructions.

The repository structure and file descriptions may be updated as the project develops.

## Requirements

The Go/No-Go experiment uses Python and PsychoPy. The R component uses R and may require additional packages.

The complete software requirements and installation instructions will be added once the code and package dependencies have been confirmed.

## Running the Project

Instructions for running the experiment and the R component will be added after the relevant code has been integrated and tested.

## Data Management

The experiment code is designed to save trial-level data in CSV format. The final output locations, variable definitions, and data-handling procedures will be documented alongside the relevant code.

Identifiable participant information and other sensitive data should not be committed to this public repository.
